# Projeto-Eng-de-Soft-ADS-Restinga-
Projeto de software voltado para avaliação física de atletas.
Nosso aplicativo nasceu de uma atividade avaliativa da cadeira logica de programação do curso ADS IFRS Campus Restinga.
A principio o aplicativo foi desenvolvido em Portugol.
Um dos nossos objetivos é transcrever o código para Python e evoluir o aplicativo conforme os requisitos que serão abordados no desenvolver do projeto.
🚀 Tecnologias Utilizadas
- ***Portugol***
- ***Python***
